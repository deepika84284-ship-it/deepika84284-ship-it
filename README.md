### 🚀 Key Projects

#### 1️⃣ [AI Smart Assistant](https://github.com/deepika84284-ship-it) `Personal Project`
> **Tech:** Python, Google Gemini API, Streamlit, python-dotenv, Embeddings, Vector Search (RAG), Antigravity IDE
- Built an AI assistant in Python with a Streamlit interface: chat screen, sidebar, PDF upload and action buttons.
- Implemented a RAG pipeline: uploaded PDF text is split into chunks, converted to embeddings and searched by vector similarity, so answers are grounded in the most relevant passages.
- Integrated the Google Gemini API to generate answers from the retrieved content; the API key is loaded securely from a .env file using python-dotenv.

#### 2️⃣ [Luna — Privacy-First Local AI Desktop Assistant](https://github.com/deepika84284-ship-it) `Luna Hackathon`
> **Tech:** Electron, React, Node.js, Express.js, Ollama (Qwen2.5 7B), Prompt Engineering
- Built a desktop AI assistant using Electron with a React frontend and Express.js backend, integrating Qwen2.5 7B as a local LLM.
- Ran Qwen2.5 7B locally through Ollama, so every AI task is processed on the user’s device and prompts and responses stay off third-party servers.
- Designed AI interaction workflows and prompts for task-based assistance, focused on privacy by processing all AI tasks locally.

#### 3️⃣ [Agri-AI System — Smart Agriculture with AI](https://github.com/deepika84284-ship-it/agri-ai-system) `Personal Project`
> **Tech:** React, TypeScript, Vite | **Live Demo:** [agri.techtigers.in](https://agri.techtigers.in)
- Built and deployed a smart agriculture web application using AI-driven logic to support farmers in making informed decisions.
- Designed 10+ reusable, modern UI components with React and TypeScript.

#### 4️⃣ Final Year Project — Student Academic Management Portal `B.E. CSE, MSEC`
> **Tech:** React, Laravel
- Built a React UI for a role-based academic management portal serving Students, Faculty/Mentors, HOD and Admin/Staff.
- Prepared module-wise architecture for the Laravel backend: database tables, API endpoints, permissions and UI mapping.
- Modules: authentication & RBAC, student profile, results, SGPA/CGPA, arrears, attendance, internal marks, mentor-mentee, placement.

#### 5️⃣ [Expense Tracker API — Backend & Database](https://github.com/deepika84284-ship-it/expense-tracker-api) `DecodeLabs Internship`
> **Tech:** Node.js, Express.js, MongoDB
- Developed a RESTful API with 5+ endpoints covering complete CRUD operations, implementing proper HTTP status codes.
- Integrated MongoDB Atlas using Mongoose for schema design and persistent data storage.
